
BizLedger AI is a lightweight, cloud-based ERP solution designed specifically for small and micro-enterprises. It simplifies financial management by using AI to automate expense categorization and generate real-time professional reports, making bookkeeping accessible for non-technical business owners.

Core Features
AI-Powered Categorization: Automatically classifies income and expenses using NLP and machine learning.

Financial Reporting: Generates instant Profit/Loss statements, Balance Sheets, and Cash Flow reports.

Intuitive Dashboard: Visualizes financial health with a proprietary "Health Score" and income vs. expense charts.



Technology Stack
Frontend: React.js (Responsive Web)

Backend: Node.js (Express)

Database: MongoDB 

AI/ML Engine: Python (scikit-learn )

Authentication: JWT (JSON Web Tokens)


System Workflow
Onboarding: Register your business.

Transaction Entry: Add data manually .

AI Classification: The engine predicts categories; you simply review or override.

Insight Generation: View real-time KPIs on your dashboard and export reports as PDF/CSV.
